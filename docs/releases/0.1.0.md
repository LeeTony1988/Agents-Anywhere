# Agents Anywhere 0.1.0

0.1.0 是 `dev/lxy` 分支的首个发布版本（2026-11-17）。它基于上游 2.3.0 的远程桌面实现，
补齐了 Android 端的鼠标模式、控制面板与画质档位，修正了 Web / Desktop 的码率与文案，
并把各端版本统一到 `0.1.0`。接口与上游 2.3.0 保持一致：契约 `remote-desktop/1.0`，
Server 迁移 `v2_56`。

## 接口变化

- **远程桌面契约 1.0**（[contracts/remote-desktop/1.0](../../contracts/remote-desktop/1.0/README.md)）：
  schema 是 wire 事实源。新增 `/api/v2/connectors/{id}/remote-desktop`、`/api/v2/remote-desktop/*`
  与会话 WebSocket；媒体面为自托管 LiveKit，输入走 LiveKit Data Packet。
  - `POST /remote-desktop/sessions` 是 create-or-join：每个 Connector 同时只有一个未结束会话；
    `mode=control` 且设备要求确认时返回 `awaiting_consent` 和 `media=null`。
  - `participantId` 由 Server 生成，LiveKit identity 为 `viewer:{participantId}`。
  - 实时事件统一 `{type,payload}`，断线用 `cursor` 补发或快照。
  - 新增 `host-control-message`（Connector ↔ `aa-screen-host` 的 NDJSON stdio 协议）与
    `clipboard-transfer`（分片剪贴板）。
- **设备设置**增加 7 个远程桌面字段：`remoteDesktopEnabled`、`remoteDesktopAllowControl`、
  `remoteDesktopRequireConsent`、`remoteDesktopAllowUnattended`、`remoteDesktopClipboard`、
  `remoteDesktopMaxFps`、`remoteDesktopMaxBitrateKbps`。默认关闭。
- **能力**新增 `connector.remote_desktop.view/control/clipboard`，带 `revision`；
  未配置 LiveKit 时 `supported=false`，客户端隐藏入口。
- **Connector RPC** 新增 `remoteDesktop.hostInfo/start/stop/updateQuality/control.grant/
  requestKeyframe/releaseAll/screenshot/input` 与对应通知。
- **错误格式**：远程桌面 HTTP 错误统一 `{"detail":{"code","message","details"}}`。

## 数据库

- Server 执行 `v2_56`：新增 `remote_desktop_sessions` 表与索引。`connector_id`/`user_id`
  不加外键，删除设备或用户时保留审计行。不存媒体 token、输入事件、剪贴板内容。

## 各端最低配套版本

| 端 | 版本 | 说明 |
| --- | --- | --- |
| Server | 0.1.0 | 远程桌面控制面与 LiveKit token 签发 |
| Connector | 0.1.0 | host 监管与 `remoteDesktop.*` RPC |
| Web | 0.1.0 | 观看/控制页面 |
| Desktop | 0.1.0 | 观看/控制页面与本机被控提示 |
| Android | 0.1.0（versionCode 13） | 观看、手势/键盘输入、鼠标模式、控制面板与截图 |
| iOS | 0.1.0（build 13） | **仅版本对齐**：远程桌面客户端尚未实现，需要 macOS + Xcode |
| DSH 插件 | 0.1.0 | 仅版本对齐，无远程桌面依赖 |

## 部署

- 可选 `livekit` 服务；未配置 `AGENT_SERVER_LIVEKIT_URL/API_KEY/API_SECRET` 时功能整体关闭，
  不影响现有部署。
- 需要开放 WebRTC/TURN 端口；企业网只放行 443 时使用 TURN/TLS 443。
- 反向代理样例：[`docker/nginx-remote-desktop.conf`](../../docker/nginx-remote-desktop.conf)、
  [`docker/Caddyfile`](../../docker/Caddyfile)。
- 可选监控：`AGENT_SERVER_METRICS_ENABLED=true`（配合 `AGENT_SERVER_METRICS_TOKEN`）暴露
  `GET /api/v2/metrics`；[`docker/prometheus.yml`](../../docker/prometheus.yml) 与
  [`docker/alerts/remote-desktop.rules.yml`](../../docker/alerts/remote-desktop.rules.yml) 可直接使用。

## 已知限制

- iOS 远程桌面客户端尚未实现，本版本只做版本对齐。
- Android 已在 API 37 模拟器验证观看、鼠标模式、控制面板、截图与横屏；真机触控、中文输入
  与长时间会话待验收。
- Windows WGC 采集已在本机交互式桌面验证；macOS / Linux 采集未实现。
- 未做多显示器切换、E2EE、录制、音频与未建会话截图预览。
- 自托管 LiveKit 不支持 JWT 吊销；抢占依赖短 TTL、`UpdateParticipant` 与 host epoch。

## 安装包记录
