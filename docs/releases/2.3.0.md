# Agents Anywhere 2.3.0

2.3.0 是一次接口更新（MINOR），**发布日期待定**。本文件是草稿：git tag、安装包、PyPI 和 npm 都还没有
切出，后续仍可能有进入这次切分的代码。相对标签
[v2.2.0](https://github.com/anywhere-labs/Agents-Anywhere/releases/tag/v2.2.0)，主线新增远程桌面
（契约 `remote-desktop/1.0`、Server 迁移 `v2_56`）。按[版本号规则](../versioning.md)，所有端版本号
统一升到 2.3.0。面向用户的变化摘要见 [CHANGELOG](../../CHANGELOG.md)。

与标签的差异：<https://github.com/anywhere-labs/Agents-Anywhere/compare/v2.2.0...main>。

## 接口变化

- **远程桌面契约 1.0**（[contracts/remote-desktop/1.0](../../contracts/remote-desktop/1.0/README.md)）：
  schema 是 wire 事实源。新增 `/api/v2/connectors/{id}/remote-desktop`、`/api/v2/remote-desktop/*`
  与会话 WebSocket；媒体面为自托管 LiveKit，输入走 LiveKit Data Packet。
  - `POST /remote-desktop/sessions` 是 create-or-join：每个 Connector 同时只有一个未结束会话；
    `mode=control` 且设备要求确认时返回 `awaiting_consent` 和 `media=null`，确认后才签发短 TTL
    controller token。
  - `participantId` 由 Server 生成，LiveKit identity 为 `viewer:{participantId}`；客户端不再自报
    `clientId` 作为安全身份。
  - 实时事件统一 `{type,payload}`，六类事件；断线用 `cursor` 补发或快照。
  - 新增 `host-control-message`（Connector ↔ `aa-screen-host` 的 NDJSON stdio 协议）与
    `clipboard-transfer`（分片剪贴板）。
- **设备设置**增加 7 个远程桌面字段：`remoteDesktopEnabled`、`remoteDesktopAllowControl`、
  `remoteDesktopRequireConsent`、`remoteDesktopAllowUnattended`、`remoteDesktopClipboard`、
  `remoteDesktopMaxFps`、`remoteDesktopMaxBitrateKbps`。默认关闭（安全默认值见 D5）。
- **能力**新增 `connector.remote_desktop.view/control/clipboard`，独立于 `ProtocolCapabilitySet`，
  带 `revision`；未配置 LiveKit 时 `supported=false`，UI 隐藏。
- **Connector RPC** 新增 `remoteDesktop.hostInfo/start/stop/updateQuality/control.grant/
  requestKeyframe/releaseAll/screenshot/input` 与对应通知。
- **错误格式**：远程桌面 HTTP 错误统一 `{"detail":{"code","message","details"}}`；`rd_*` 只作为
  Connector 内部码。

## 数据库

- Server 执行 `v2_56`：新增 `remote_desktop_sessions` 表与索引。`connector_id`/`user_id` 不加外键，
  删除设备或用户时保留审计行。不存媒体 token、输入事件、剪贴板内容。

## 部署

- 新增可选 `livekit` 服务；未配置 `AGENT_SERVER_LIVEKIT_URL/API_KEY/API_SECRET` 时功能整体关闭，
  不影响现有部署。
- 需要开放 WebRTC/TURN 端口；企业网只放行 443 时使用 TURN/TLS 443。
- 反向代理样例：[`docker/nginx-remote-desktop.conf`](../../docker/nginx-remote-desktop.conf)、
  [`docker/Caddyfile`](../../docker/Caddyfile)（会话 WebSocket 升级、webhook body 原样透传、请求体上限）。
- 可选监控：`AGENT_SERVER_METRICS_ENABLED=true`（配 `AGENT_SERVER_METRICS_TOKEN`）暴露
  `GET /api/v2/metrics`；[`docker/prometheus.yml`](../../docker/prometheus.yml) 与
  [`docker/alerts/remote-desktop.rules.yml`](../../docker/alerts/remote-desktop.rules.yml) 可直接使用，
  compose 里用 `--profile monitoring` 启动。
- 本版本不包含真实 host 二进制的公开发布记录；打包脚本（`screen-host/scripts/package.ps1`）与
  sha256 校验已就绪，签名/公证见 P2 剩余工作。
- 截图接口支持 `jpeg`/`png`（灰度），响应里的 `format` 是实际格式。
- 开发专用开关（不要用于生产）：`AGENT_CONNECTOR_REMOTE_DESKTOP_CONSENT_PROMPT`、
  `AGENT_CONNECTOR_REMOTE_DESKTOP_SYNTHETIC_CAPTURE`（合成采集，仅用于无桌面环境验证媒体链路）。

## 已知限制

- Windows-first：真实 WGC 采集尚未在交互式桌面上验收（开发环境是 Windows session 0，WGC/DXGI
  返回 Access Denied）；macOS/Linux 后续阶段。
- 但**媒体链路本身已端到端验证**：合成采集（`AA_SCREEN_HOST_SYNTHETIC_CAPTURE`）→ VP8 →
  自托管 LiveKit → 浏览器 `<video>` 解出 640×360/`readyState=4`，见
  [`server/scripts/e2e_full_chain.py --browser`](../../server/scripts/e2e_full_chain.py)。
- Android 只做到编译、单测、lint 与 `assembleDebug`；真机观看/手势/中文输入未验收。iOS 未开始。
- 未验证：`docker compose up` 的真实部署、TURN 与 4G/企业网 ICE、代码签名与公证、双机多显示器点选精度。
- 未做无人值守、多显示器切换、E2EE、录制、音频、未建会话截图预览。
- 自托管 LiveKit 不支持 JWT 吊销；抢占依赖短 TTL + `UpdateParticipant` + host epoch。
- Android/iOS/Desktop 的远程桌面 UI 在本分支尚未交付，见实现计划 P3–P5。
